# The Human Consensus

個人情報を1文字も残さない、プライバシー保護型の意思決定ツールを開発中です。

## 目指していること
- 個人情報をサーバーに保存しない
- 選択内容を外部に証明できない設計（ZKP + MACI）
- eSIM由来のDIDで参加者を区別

## 現状
- 仕様検討・構想段階
- 技術知識ほぼゼロの個人開発です
- プロのエンジニアからの意見・指摘を強く求めています

## 技術スタック（予定）
- DID（eSIMベース）
- zk-SNARKs
- MACI
